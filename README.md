# Job Prep Plan — 14 дней

Интерактивный русскоязычный кабинет подготовки к вакансиям Product Data, E-commerce и Reporting Assistant.

## Запуск локально
1. Скачай ZIP и распакуй.
2. Открой `index.html` в браузере.

## Публикация через GitHub Pages
1. Создай на GitHub новый репозиторий, например `job-prep-plan`.
2. Загрузи в него файлы `index.html`, `styles.css`, `app.js`, `README.md` (можно через **Add file → Upload files**).
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`, нажми **Save**.
6. Через минуту GitHub покажет ссылку вида `https://USERNAME.github.io/job-prep-plan/`.

## Возможности
- Навигация по разделам и неделям.
- Чек-листы и сохранение отметок в браузере (`localStorage`).
- Поля для ответов на интервью.
- Трекер откликов и вакансий.
- Адаптивный интерфейс для телефона и компьютера.

### Важно
Прогресс хранится в браузере на конкретном устройстве. GitHub Pages публикует сайт, но не синхронизирует данные между устройствами.
